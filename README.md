# Dork Engine

Dork generation and manual validation engine for job search.

## Current Phase

Phase 0 — Dork Engine Validation

## Objective

Build and validate a catalog of search dorks
that reliably identify relevant job listings.

## Current Scope

- Dork catalog
- Dork generation
- Manual testing
- Result evaluation
- Dork iteration

## Out of Scope

- Automated scraping
- Proxy management
- CAPTCHA handling
- Job ranking
- Production infrastructure
